# KratOS Website Implementation Plan

> For agentic workers: use superpowers:executing-plans. The user explicitly requested planning, design and implementation in one run; do not pause for stage approvals.

**Goal:** Build the complete responsive trilingual KratOS website ready for review locally and deployment to Cloudflare after business details are supplied.
**Architecture:** Astro static pages share translated content, layout and reusable editorial components. TypeScript handles progressive enhancement. A local enquiry draft is the honest fallback for an unconfigured delivery workflow.
**Tech Stack:** Astro, TypeScript, CSS, self-hosted fonts, Cloudflare Workers Static Assets.
**Spec:** docs/superpowers/specs/2026-10-08-site-design.md and kratos-website-design-spec.md.

## Global constraints
- All visible copy, validation and metadata localized in English, Sinhala, Tamil.
- User supplies final logo/photos/client assets; original reference retained unchanged.
- No fabricated client proof, contact details or submission success.
- Use whitespace, restrained orange, geometric artwork; no photo hero or generic dashboard.
- Local preview only in this run; no production deployment requested.

## Review focus
- Language switch on nested case studies must keep the same page.
- Missing contact config must never open a fabricated recipient.
- Unicode enquiry text must survive download and URL encoding.
- Long Tamil/Sinhala text must not overflow mobile layouts.
- Preview content must not be indexed as completed client work.
